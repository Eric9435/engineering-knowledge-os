# Engineering Knowledge OS — Application

Engineering domain/topic content, code and formula references, graph views, and a browser-local notebook.

## Run from this directory

Use Node.js 22 and npm.

```bash
npm install
npm run dev
npm run lint
npm run build
```

The AI Tutor page is a scaffold. Notebook records use localStorage and do not provide cloud account sync. Review technical content against authoritative references.

For full project features, architecture, configuration, and limitations, see the [repository README](../README.md).
